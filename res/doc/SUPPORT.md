## Getting Help

If you encounter issues or have questions:

- [Open an issue](https://github.com/zouari-oss/hashhash-books/issues)
- Read the [installation](INSTALL.md) and [usage](USAGE.md) guides
- Contact the maintainers (see the README)

## Reporting Bugs

Please include:

- Operating system
- Node.js version
- Steps to reproduce
- Expected behavior
- Actual behavior

## Content Requests

Missing a book, a topic, or found an error in a note? Open an issue using the matching template,
or contribute it yourself following [CONTRIBUTING.md](../../.github/CONTRIBUTING.md).

## Security Issues

Please do not report security vulnerabilities publicly.
Refer to [SECURITY.md](../../.github/SECURITY.md) for responsible disclosure.
