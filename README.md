## Overview

**HashHashBooks** is a curated collection of programming books and notes to help developers of all
levels master coding concepts, improve their skills, and stay updated with the latest technologies.
Every file is published automatically as a searchable website.

## Key Features

- **Wide Coverage:** Programming languages, web, data science, AI, DevOps, security, and more.
- **Books and Notes:** PDFs, cheat sheets, slides, and Markdown guides organized per topic.
- **Automatic Website:** Drop a file under `content/`, push, and it is published with sidebar and search.
- **Zero Configuration:** A new folder becomes a new topic, with no setup required.
- **Enforced Layout:** `make lint` keeps naming and structure consistent as the collection grows.

## Quick Start

Clone the repository and follow the [installation guide](res/doc/INSTALL.md).

```bash
git clone https://github.com/zouari-oss/hashhash-books.git
cd hashhash-books
make
```
